# LifeLine – Blood Bank Management System

A frontend mini-project built using HTML, CSS and JavaScript.

## Features
- Dashboard with donor, stock and request summaries
- Donor registration, search and delete
- Blood inventory quantity updates for eight blood groups
- Blood request submission and status tracking
- Demo localStorage persistence

## Requirements
- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (optional)

## Run the project
1. Extract the ZIP file.
2. Open the `Blood-Bank-Management-System` folder in VS Code.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server**, or double-click `index.html` to open it in a browser.

## Data storage
The project uses browser `localStorage`. Data remains in the same browser profile on the same device. Clearing browser site data may delete it. This is a frontend demonstration and does not provide shared team storage, authentication, a secure backend, or a real blood-bank inventory.

## Important limitation
This project is for educational demonstration only. It must not be used for real donor eligibility decisions, blood availability confirmation, patient care, or transfusion decisions.
